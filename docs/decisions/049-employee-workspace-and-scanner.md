# 049 — Рабочий экран и очередь сканера

Дата: 2026-10-24. Статус: принято.

`/work` открывается после входа сотрудника. Начало смены и явное взятие задания ведут к одному текущему действию без управленческой навигации. Меню содержит перерыв/конец смены, другие работы и помощь. Переносимый короб/паллета имеют приоритет над новой работой; добровольное размещение не захватывается автоматически.

EmployeeScan в shared не знает доменных сущностей: передаёт реальный ввод в callback и сериализует подтверждения. Каждое одинаковое сканирование товара — отдельная единица. Очередь ограничена 50 ожидающими сканами. Для источника/короба повторный Enter блокируется до ответа. Неверный код сохраняется и останавливает очередь; исправление заменяет непринятый элемент, затем обработка продолжается. Потеря контекста/auth закрывает неотправленные элементы с сообщением; уже отправленную команду защищает существующий requestId/replay. Клиент не прибавляет количество до подтверждения сервера.

EmployeeScanBoundary объединяет ожидающие сканы и несохранённый подсчёт. Пока они есть, меню не переводит на другую работу и не завершает смену; beforeunload предупреждает об уходе. При внешней смене приоритета/смены текущий экран остаётся смонтированным с сообщением. При паузе можно возобновить смену через меню. Dirty-пересчёт не исчезает после failed polling или external submit; недоступные записи блокируются существующими canCount/revision и API. Явная очистка проходит через подтверждение формы. Авторизация и смена личности сохраняют прежние auth-epoch guards.

FSD: widget компонует независимые features через публичные exports. Workday держит только режим и команду собственной смены с синхронной защитой от повторного клика. Контракты и endpoint-ы не менялись. Миграции БД отсутствуют.

Проверка: unit-тесты очереди, выбора работы/приоритета и компактных сценариев; браузер 390 CSS px, неверный код, серия одинаковых Enter, автоматическое закрытие короба, сканы источника/короба, забор/размещение, блокировка ухода с грузом, приёмка, dirty-пересчёт и перерыв. Реальное оборудование требует отдельного прогона.

# ADR 003. Визуальный язык и интерфейс WMS

Дата: 23 октября 2026. Статус: принято для первого интерактивного прототипа.

## Направление

Интерфейс соединяет плотность терминала для торговли с прозрачными слоями Apple Liquid Glass. Криптовалютная эстетика выражена в графике, ритме и точных числах; продукт показывает только реальные складские показатели. Никаких вымышленных курсов, процентов роста или декоративных графиков.

Основная палитра: тёмный charcoal с едва заметным forest-оттенком. Единственный основной акцент — mint/emerald. Amber и coral используются только для предупреждений и ошибок. Цвета заданы в OKLCH, семантические CSS-токены: `--bg`, `--surface`, `--surface-raised`, `--text`, `--muted`, `--accent`, `--accent-ink`, `--border`, `--danger`, `--warning`.

Поверхности показывают глубину через светлоту, тонкую светлую границу, внутренний блик и умеренный blur. Прозрачность не должна мешать чтению. Главный отличительный элемент обзора — схема занятых ячеек с условным изображением паллет. Это обзор ячеек, а не геометрическая карта; точное размещение редактируется на отдельной карте склада.

Типографика: Manrope с кириллицей; числа с tabular-nums; технические коды на системном моноширинном шрифте. Сейчас Manrope загружается через Google Fonts; системный fallback оставляет приложение рабочим при отсутствии доступа. Перед production следует разместить WOFF2 локально. Сетка отступов — 4/8 px, 16–24 px между блоками. На экране 1440 px фиксированная левая панель, контент адаптируется. На телефоне навигация раскрывается поверх контента; показатели перестраиваются в две колонки, остальные панели — в одну.

## Архитектура

- `widgets/workspace-shell` — навигация, верхняя панель, выбор раздела и каркас рабочего пространства.
- `features/dashboard` — экран операционного обзора, вычисляет показатели из snapshot API.
- `entities/workspace` — чтение состояния; все типы приходят из OpenAPI/Orval.
- `shared/ui` — Button, Input, Select, Modal, Badge, EmptyState, LoadingState, ErrorState.
- Глобальные токены и базовые стили — `app/globals.css`. Без параллельной системы Tailwind.
- Каждый модуль предоставляет публичный `index.ts`/`index.tsx`. Импорты идут вниз по слоям FSD. UI-примитивы не знают о бизнес-сущностях.

## Работа интерфейса

Все навигационные элементы ведут на настоящие разделы. Поиск по разделам открывается по кнопке или Cmd/Ctrl+K. Диалоги используют нативный `dialog`, чтобы сохранялись фокус, Escape и блокировка фонового содержимого. У форм есть подписи, у иконок-кнопок — доступные названия. Видимый focus, ссылка пропуска навигации, reduced motion и отдельные состояния загрузки/ошибки/пустого списка обязательны.

Показатели вычисляются из текущих записей: неупакованные единицы на входящих паллетах, число готовых коробов и единиц в них, накопленный результат сборки сотрудников, доля занятых доступных адресов хранения (стеллажи и напольные места). Загрузка адресов считается по наличию товара и не заменяет проверку физической вместимости. Журнал сортируется по времени событий, отображается в московском часовом поясе. Отсутствие данных не заменяется выдуманными значениями.

## Ограничения первого среза

Карта в обзоре показывает максимум 18 ячеек. Проверка контраста и браузерная проверка обязательны при итоговой интеграции. Мягкие hover-эффекты используют CSS; отдельная библиотека анимации не нужна.

## Прозрачность демонстрационного режима

Каркас явно помечает локальный деморежим, демонстрационный доступ без авторизации и локальное сохранение данных. Накопительные counters сотрудников подписаны как общий результат, без утверждений о текущем дне или отдельной смене, пока нет серверного учёта периодов.

# ADR073: утраченная поставка и запуск новинок

Дата: 2026-10-27. Статус: принято.

Руководитель подтвердил утрату старой поставки «Мандал», отсутствие «Собачек» и «Нового года» на WB и необходимость планировать их запуск. Отсутствующая строка API сама по себе не означает нулевой остаток. Исходные документы, история импорта и наблюдения наличия сохраняются.

Schema17 добавляет отдельные marketplace_resolutions и append-only marketplace_resolution_events. Manager-команда с CSRF и replay проверяет действующий магазин, карточку/сопоставление или документ. Уточнение привязано к storeId и версии подключения; запуск также к аккаунту и версии донора. Публичная проекция не содержит идентификатора магазина, автора или секретов. Уточнения отменяются; не создают складские движения, фиктивные короба, задачи или наблюдения для обучения.

Исключение относится к конкретной поставке WB. Только затронутые позиции товара в пути пересчитываются по оставшимся документам. Неизвестные количества остальных поставок остаются неизвестными. Новые поставки той же тематики не исключаются. Исходный документ по-прежнему доступен.

Подтверждение нулевого остатка действует семь дней и применяется только к полному снимку каталога/остатков действующего подключения при отсутствии числового остатка API. Любое числовое значение API приоритетнее. Положительный остаток при успешной публикации окончательно отключает старое подтверждение с системным событием; последующий сбой не оживляет его. Это факт для планирования, а не источник синтетической истории наличия.

Запуск задаётся явно для карточки. Предварительный сценарий использует прогноз той же тематики на второй площадке, умноженный на медианное соотношение чистых заказов двух площадок по минимум трём сопоставимым тематикам с одинаковой упаковкой. Окно сравнения — 56 дней; для каждого аналога нужны минимум 14 совместных известных дней после появления, минимум три дня положительного спроса и пять единиц на каждой площадке. Известные нулевые дни входят; неизвестные дни и наблюдавшийся stockout исключаются. Финансовые выкупы/возвраты не смешиваются с заказами. Коэффициент ограничен 0,25–4 как защита малой выборки, не как доказанная граница спроса.

Новогодняя кривая донора масштабируется один раз. Сценарий честно обозначен как предварительный, не выдаётся за проверенный ML. Недостаточно донора/аналогов — прогноз остаётся неизвестным. После 14 собственных известных дней доступности применяется собственный прогноз. Сценарий не записывается в историю продаж и не подаётся как фактическая обучающая выборка. Worker и fallback используют одну чистую функцию; worker имеет полную историю, fallback — полный текущий снимок, поэтому временные предварительные количества могут отличаться.

Активные уточнения входят в ключ worker и совместимость сохранённого плана. Изменение или истечение уточнения инвалидирует прежние рекомендации; обычное фоновое обновление сохраняет прежний совместимый план. UI получает DTO через Swagger/Orval, показывает результат и редкую раскрываемую форму «Уточнения плана», не считает прогноз на клиенте.

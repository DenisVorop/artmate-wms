# ADR086 — европаллета, выступ груза и42 короба

Дата:2026-10-29. Статус:принято по фактическому обмеру пользователя.

## Подтверждённая физика

Поддон всегда1200×800мм. Короб450×350×200мм,6 коробов в слое с выступом:
раскладка3×2 занимает1050×900мм, полный габарит с основанием1200×900мм.
7 слоёв дают42 короба и1550мм высоты с поддоном150мм.

Верхний лимит всех102 активных адресов42; полезная высота остаётся независимой.
На77/78см помещается3 слоя (18коробов), на101,5/103см4слоя (24), на150см6слоёв
(36). Только адрес с достаточной высотой принимает полные42. Обмеры стеллажей
ради лимита не повышаются. Масса и доступность проверяются по прежним правилам.

Пользователь подтвердил14,4м вдоль стены: F-01…F-16 сохранены, шаг900мм,
рядY14…28,4. Их глубина1,3м/полезные1250мм сохраняет место для длинной стороны
европаллеты. Центральный проход продлён доY28,4. PACK-01/T-01/T-02 занимают
1200×900мм с полезными такими же габаритами. Это место под загруженный поддон,
сам деревянный поддон не становится1200×900.

Новые места/секции конструктора получают1,2×0,9м, полезные1200×900мм, maxBoxes42.
Existing defaults не заменяют индивидуальные настройки существующих адресов.

## Контракт и расчёт

PackagingProfileDto расширен optional loadWidthMm/loadDepthMm: полные габариты
загруженной паллеты, не меньше основания. Отсутствующие поля означают размер
основания; null/нецелые/меньшие значения отклоняются. Исторические снимки не
переписываются. Источник — NestDTO→Swagger→Orval; web дополнительно проверяет
optional-геометрию вSKU и снимках паллет/коробов.

finishedMetrics/assemblyMetrics считают габариты непустой паллеты с выступом.
Пустой поддон сохраняет базовые размеры. Смешанный накопитель использует общий
консервативный grid; расширить его может только явный load, другой implicitbase
старого профиля не увеличивает фиксированное основание. samePackaging считает
старый missingload и explicitload=base совместимыми, но реальный выступ — иной
упаковкой. Проверки высоты/занятости/FIFO/резервов сохраняются.

Вместимость/давление общего накопителя используют тот же расчёт. Сохранённый
пустой накопитель со старымDEMO-профилем не должен продолжать ограничивать новую
сборку36коробами: без коробов и начатой работы для расчёта выбирается актуальный
профильSKU, само основание/исторический снимок не меняются.

DEFAULT_PACKAGING для новых SKU — подтверждённый профиль450×350×200/6×7/груз1200×900.
DEMO_PACKAGING сохранён для старых fixtures/истории; индивидуальные профили не
подменяются при чтении. Параметры существующих реальных раскрасок обновляются
отдельной административной операцией без незавершённой сборки; снимки готовых
коробов/паллет остаются прежними. Профиль маркеров и тестовых SKU отдельно не
выдумывается.

## Универсальное временное хранение

T остаются floor: сырьё или готовая продукция без назначения конкретной тематики
адресу. Правило одной тематики на обычной учтённой паллете сохраняется. Упаковка
и вещи без товарного учёта не объявляются учтённым остатком: содержимое можно
указать в имени и закрыть адрес для нового размещения существующим blocked.
После освобождения адрес открывается. Новый журнал материалов не вводится.

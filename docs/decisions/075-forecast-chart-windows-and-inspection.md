# ADR075: период и чтение графиков прогноза

Дата: 2026-10-27. Статус: принято.

Пользователь увидел горизонтальные прогнозы и попросил выбор периода, значения по наведению и, по возможности, суммы продаж. Проверка сохранённой проекции обнаружила 53 меняющихся ряда из 80: полная история с пиками 2025 года сжимала короткий прогноз. Есть и действительно постоянные оценки. SVG не терял вариацию при округлении.

Период графика — локальное состояние feature/forecasting/lib, отдельно от периода недавнего спроса, обучения и параметров плана. По умолчанию последние 30 календарных дней истории и ближайшие 30 дней прогноза; доступны 90 дней/год истории с месячным прогнозом, весь доступный период и собственные включительные даты. Никакого импорта, обучения или складской команды при изменении вида. Одинаковые даты выравниваются по общей X-шкале всех источников; Y-шкала каждого источника определяется только выбранным периодом и начинается с нуля.

Факт и прогноз остаются раздельными. Итоги и число известных дней относятся к видимым данным; неизвестное количество не становится нулём. Внутренние пропуски разрывают линию, недостающие точки не добавляются. Граница и фон будущего, ось количества, указатель даты и tooltip позволяют читать значения с мыши, касанием и клавиатурой. Постоянный прогноз не получает выдуманных колебаний; его одинаковая дневная оценка подписана явно.

В сохранённом HistoryFact и ForecastChartPointDto есть количества без цены/выручки. Рубли не выводятся из текущей цены товара. Реальная выручка потребует отдельной денежной метрики и импорта с валютой/возвратами; в этом изменении показаны только реальные количества и прогнозные единицы. Название источника определяет смысл: заказы, выкупы, возвраты и сценарий запуска не суммируются между собой.

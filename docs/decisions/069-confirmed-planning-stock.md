# ADR069 — подтверждённый готовый остаток для плана

Дата: 2026-10-26. Статус: принято.

## Решение

При первоначальном учёте руководитель может знать общее количество готового товара, не имея QR, адресов, состава партий и дат упаковки. Эти сведения сохраняются отдельной подтверждённой оценкой для планирования, без создания складских коробов, приходов, выработки и FIFO-дат.

На момент подтверждения сохраняются заявленный общий остаток, текущий учтённый готовый остаток, упаковка, автор, время, точность, причина и версия. План использует неразмеченную разницу плюс текущий учтённый товар. Черновые резервы учитываются один раз. Доступность для физической отгрузки не увеличивается. Отрицательная разница и изменение упаковки блокируют использование. Приблизительный, просроченный или затронутый новой внешней поставкой неразмеченный запас требует проверки; он не разрешает автоматическое создание задания.

Подтверждения хранятся отдельно от Workspace и журнала движения товара, с append-only историей изменений. Команда руководителя защищена сессией/CSRF и requestId, проверяет права до replay, атомарно обрабатывает пакет. Данные входят в proposalHash, но не меняют обучение модели спроса. Снятая с продажи тематика исключается только из плана, без потери каталога и складской истории.

## Ограничения

Отправка старого неразмеченного товара вне WMS требует уменьшить или повторно подтвердить остаток. Интеграция не может доказать, какие именно короба ушли. При будущем присвоении QR старым коробам необходимо атомарно переводить количество из неразмеченного пула. Нельзя считать регистрацию старого товара новой сборкой. Данный срез не заменяет адресную инвентаризацию.

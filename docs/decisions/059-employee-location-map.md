# 059. Компактная карта рабочего адреса

Кнопка «Показать на карте» открывает небольшую пространственную подсказку непосредственно из текущего шага. Native dialog позволяет быстро вернуться к скану и не сдвигает сканер длинной картой ниже экрана. Полная форма остаётся смонтированной; карта не выполняет складских команд. Основание: явный запрос владельца на небольшую карту при открытии; product-design rule/preserve-user-input, rule/one-primary-action, rule/inline-before-modal (рассмотрено inline; оно сдвигает рабочее поле на маленьком телефоне).

entities/warehouse-map строит read-only проекцию переданной геометрии. Features передают стабильный locationId и контекст операции; запрещено угадывать объект по коду адреса или импортировать editor feature в соседнюю feature. Настройки стеллажа/уровней/входов совпадают с существующей схемой: x/y — верхний левый угол физического footprint, 90/270 меняют ширину/глубину местами. Несколько ярусов изображаются одной секцией; точный ярус указан текстом рядом с кодом.

По умолчанию показывается помещение или коридор, содержащий целевой адрес, с подсветкой цели; «Весь склад» даёт общий контекст помещений; пустое рабочее поле редактора не уменьшает масштаб реальной схемы. Архивные адреса/секции не подменяются ближайшими объектами. Если цель недоступна, показано понятное состояние, сохраняется возможность закрытия. Ни GPS сотрудника, ни рассчитанный маршрут не выдумываются.

Текущий шаг, актор и адрес определяют время жизни подсказки. При смене контекста/авторизации карта закрывается, чтобы не направить к прежней цели. Native modal ограничивает фокус, Escape/кнопка закрывают, фокус возвращается в поле сканирования текущей операции. Помеченное data-employee-scan-input поле ищется только внутри текущей секции; временно заблокированное поле не оставляет фокус на кнопке карты, чтобы Enter сканера не открыл её повторно. Открытие не сбрасывает ошибочный или сохранённый первый скан и доступно для просмотра без изменения факта переноса.

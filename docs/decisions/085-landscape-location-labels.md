# ADR 085 — горизонтальные этикетки адресов

Дата: 2026-10-29. Статус: принято.

Утверждённый пользователем PDF-шаблон перенесён в WMS: один адрес на страницу
120 × 75 мм, QR слева (73 мм с белыми полями), справа номер места и ярус,
внизу исходный код адреса. Длинные названия склада/стеллажа и payload не печатаются.

Shared LocationRollLabel используется одиночной и массовой печатью. Новый формат
по умолчанию для адресов и /labels/a4; А4 и прежние размеры остаются в выборе.
Named page wmsRoll120 независима от остальных. Короба, паллеты и приёмки сохраняют
прежний формат. Зоны в смешанном горизонтальном комплекте используют общий RollLabel.

Номер физического места берётся из явного сегмента «место N» существующего названия;
номер яруса — из «ярус N». Нельзя считать номер по модулю кода: есть стеллажи на две
и три паллеты. Для произвольных названий используется полный адрес без выдуманного
номера/яруса. Архивная пометка сохраняется. Это только представление; API, QR,
идентификаторы и складские имена не меняются. Готовность QR сохраняется для каждой
попытки и формата, неполный комплект при native print не выводится.

В драйвере рулон остаётся 75 × 120 мм, альбомная ориентация, масштаб 100%,
без полей и колонтитулов. Поворот бумажного макета не меняет ширину ленты принтера.

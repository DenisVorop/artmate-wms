# ADR083 — экран и звуковая обратная связь сотрудника

Дата: 28 октября 2026.

## Решение

Рабочий экран /work удерживается включённым, пока собственная смена имеет статус working и документ видим. На перерыве, выходе, смене аккаунта или закрытии страницы ресурсы освобождаются. После возврата из фона удержание запрашивается заново. Поздний ответ старого запроса освобождает свой sentinel и не заменяет новую сессию. Отказ/системное освобождение показываются явно; бесконечного цикла повторных запросов нет.

Один AudioContext принадлежит сессии рабочего экрана. Звук включён по умолчанию: касание, щелчок или клавиша сканера автоматически активируют AudioContext. Первое касание может быть нажатием «Начать смену»; контекст сохраняется после её запуска. После аудиопрерывания следующий пользовательский жест возобновляет звук. При остановке смены сигналы прекращаются. В меню показано предупреждение, если звук недоступен. Никаких сетевых аудиофайлов, фонового воспроизведения или обхода ограничений iOS.

Shared EmployeeScan озвучивает результат onScan, а не помещение кода в очередь. Для серверной команды сигнал следует после её ответа; локально проверенный первый код пары подтверждает только текущий шаг, не изменение остатков. Gateway pass не звучит и остаётся синхронным; handled/blocked звучат после результата перехватчика. Ошибка валидации, отклонённый код или сбой команды дают сигнал ошибки. Очередь сохраняет прежнее поведение остановки и восстановления. Камера/ручной ввод/HID используют один путь. Завершивший короб скан может успешно сменить форму до возврата ответа — это не причина терять подтверждающий звук. Ответы прежнего auth epoch молчат.

Успех: два коротких высоких тона. Ошибка: один мягкий низкий протяжный гудок с высокой амплитудой. Новый результат прекращает предыдущие тона, чтобы не накапливать устаревшие звуки при серии сканов. Сигнал ошибки имеет приоритет до завершения своего гудка: подтверждение последнего скана не заглушает предупреждение о сброшенном хвосте очереди. Звуки не являются заменой экранной ошибки; физический писк сканера означает только чтение кода. Ошибка браузерного аудио не влияет на складскую команду.

## Границы

Механика устройства — shared/lib и shared/ui; виджет задаёт только active/sessionKey из текущего пользователя и смены. API и складской учёт не меняются. Удержание требует защищённого контекста и поддержки браузера. Энергосбережение, ручная блокировка, переключение приложения и системные аудионастройки остаются под контролем телефона. Нельзя обещать сканирование заблокированным телефоном или слышимость на любом устройстве без физической проверки.

Источники: [Screen Wake Lock](https://www.w3.org/TR/screen-wake-lock/), [WebKit: Safari 18.4 и Home Screen Web Apps](https://webkit.org/blog/16574/webkit-features-in-safari-18-4/).

## Уточнение от 28 октября 2026

По результату проверки пользователем низкий сигнал ошибки оказался глухим. Заменён на три прямоугольных тона 2349/1760/2349 Гц по 160 мс с паузами 80 мс и удержанием амплитуды 0,32; прежний успех 1046/1397 Гц, sine, 0,18 сохранён. Защита от перебивания успехом следует новой длительности ошибки (720 мс). Реальная слышимость зависит от громкости/беззвучного режима телефона; пользователь подтвердил, что на его iPhone после включения звука воспроизведение работает.

## Второе уточнение от 28 октября 2026

По следующему запросу пользователя пробуем более глухое «ыыы»: один прямоугольный тон 260 Гц длительностью 420 мс, амплитуда 0,45 с удержанием. Пользователь уточнил, что два гудка были лишь примером: повтор не нужен. Блокировка перебивания следует длительности одного гудка (420 мс). Успешный сигнал прежний. Этот вариант заменяет звонкую тройку из предыдущего уточнения; оценка тембра и слышимости — пользователем на телефоне.

## Третье уточнение от 28 октября 2026

После прослушивания одиночного прямоугольного гудка пользователь попросил ещё более глухой тембр, ориентир — звук ошибки Ozon/WB. Точный образец не предоставлен, воспроизведение оригинала не заявляется. Выбран один треугольный тон 185 Гц, 450 мс, амплитуда 0,72 с удержанием: ниже и мягче предыдущего, без ярких гармоник прямоугольной волны. Повтора нет. Защита от перебивания следует новым 450 мс; успех сохранён.

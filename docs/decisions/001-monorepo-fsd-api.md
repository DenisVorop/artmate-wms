# ADR-001 — монорепозиторий, FSD и генерация API

Дата: 23 октября 2026 года. Решение: пользователь выбрал Next.js, NestJS и Swagger/OpenAPI → Orval; реализация использует Yarn Classic workspaces и Turborepo по образцу соседнего проекта.

FSD сохраняет thin routes, композицию страниц, feature workflows, entity reads и shared infrastructure. Общего пакета API-контрактов нет. Generated API находится в web/shared/api. Публичные экспорты слайсов и проверка направления импортов защищают границы.

Серверные DTO — источник схемы; runtime ValidationPipe — источник проверки входа. Генерация запускается перед typecheck/build. Общий snapshot позволяет первой версии синхронизировать экраны после транзакции; дробление query-моделей выполняется по реальному росту.

Код соседнего проекта изучается как архитектурный образец. Зависимости от его базы, секретов и приватных модулей не создаются.

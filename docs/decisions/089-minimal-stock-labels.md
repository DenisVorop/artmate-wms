# 089. Минимальные товарные этикетки и физические форматы

Дата: 2026-11-06. Пользователь подтвердил рулон коробов58×40мм, паллеты75×120мм
или целый А4. Служебный текст прежних макетов переносился и мешал чтению.

Общий shared/ui/StockLabel используется запасными комплектами, приёмкой,
одиночной печатью и первичной инвентаризацией. Короб — только QR, без видимых
подписей, UUID, тематики и пояснений; стандарт58×40 с QR36мм по центру.
Паллета — заголовок, QR65мм и короткая читаемая ссылка на комплект/номер;
на А4 QR180мм, одна паллета на страницу. Полный неизменный идентификатор
передаётся в QR, а не печатается длинной строкой. Существующий PLT-PRE при
повторной печати показывает последние8символов только как визуальный ориентир.
Цвета чёрный/белый, Arial, нормальное межбуквенное расстояние, без брендинга.
Светлая рамка предпросмотра — outline, не уменьшающий физическую область QR.

Named @page задают58×40,75×120 и А4. Предпросмотр и печать — один компонент,
внешняя UI-форма скрыта при печати. SVG readiness, blocking при ошибках,
пагинация, права и неизменяемость кодов сохранены. Начальный ввод печатается
отдельно по типу: паллеты или короба, чтобы размеры не смешивались в одном тираже.
Реестр и API не меняются, миграций нет. Схема и этикетки мест/зон не затронуты.


Проверка Chromium print preview обнаружила пустую первую anonymous-страницу перед
named page этикетки. Формат применяется к печатному контейнеру и body:has(...),
поэтому первый лист сразу имеет выбранное имя/размер. Колонтитулы не становятся
содержимым отдельного А4. Проверять именно диалог/PDF, не только экранный размер.

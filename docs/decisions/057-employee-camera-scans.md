# 057. Сканирование камерой сотрудника

Камера — дополнительный источник кода в Shared EmployeeScan. Распознанная строка проходит ту же валидацию, перехват QR рабочих зон, последовательную очередь и проверки сервером, что HID и ручной ввод. Складские правила остаются в features/widgets и API.

Одно открытие камеры принимает только один код и закрывается. Следующий одинаковый штрихкод можно отсканировать новым открытием: это отдельная единица товара. Нельзя учитывать один неподвижный кадр многократно. Камера открывается только по действию сотрудника, использует заднюю камеру без звука. При закрытии, уходе со страницы или смене контекста поток завершается; поздний ответ разрешения или распознавания не отправляет код.

ZXing загружается динамически локальным приложением: BarcodeDetector доступен не во всех браузерах. Телефон использует существующий HTTPS-доступ; отказ в разрешении не блокирует HID и ручной ввод.

Источники: [MDN getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia), [MDN Barcode Detection API](https://developer.mozilla.org/en-US/docs/Web/API/Barcode_Detection_API), [ZXing browser](https://github.com/zxing-js/browser).

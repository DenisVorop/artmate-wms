# Подключение и план сборки

Откройте «Маркетплейсы» под руководителем. Добавьте Wildberries и/или Ozon. Для WB нужен персональный токен только для чтения с категориями Контент, Статистика, Аналитика и Поставки. Для Ozon — Client ID и отдельный ключ с чтением каталога, FBO-отправлений аналитики остатков и документов поставок. Не отправляйте ключи в чат; введите их в форму WMS. Сохранённый ключ ещё не означает успешное подключение.

После подключения WMS автоматически загружает продажи, остатки и поставки каждые 30 минут — в :00 и :30. При запуске сервер проверяет текущий пропущенный цикл. Компьютер и сервер WMS должны работать; после сна выполняется один актуальный цикл без очереди прошлых запусков. Из-за лимитов площадок загрузка занимает несколько минут. Дата последней успешной загрузки видна в карточке подключения. При ошибке предыдущие данные сохраняются, следующая попытка — в очередном цикле. Ручное «Обновить сейчас» доступно внутри «Настроек подключения». Открытый план сам получает готовый результат с сервера каждые30секунд.

Если тематики ещё нет, нажмите «Добавить тематику» в каталоге: укажите название, штрихкод и количество единиц в транспортном коробе. Код создаётся автоматически. Это запись справочника без приёмки и начисления остатков; одинаковый штрихкод с совпадающими параметрами использует существующую тематику, конфликтующие данные отклоняются. Сценарий доступен только руководителю.

В каталоге выберите тематику и количество единиц WMS в одной продаваемой упаковке. Одна книга или один набор маркеров считается одной единицей: 25 картин внутри книги и 168 цветов внутри набора не являются множителями количества. Если продаётся одна раскраска, укажите 1; для набора из 10 — 10. Нажмите «Сохранить»: предложение по штрихкоду само по себе связь не создаёт. Для расчёта необходимо сопоставить загруженные карточки включённых площадок.

В «Плане сборки» задайте период истории, горизонт запаса, страховые дни и срок доставки. Если история длиннее предыдущей загрузки, расчёт уточнится в следующем автоматическом цикле. Загрузка получает ровно заданный период истории, без дополнительного скрытого запаса дней. Расчёт использует полные дни по Москве. Он показывает оперативный спрос по заказам минус отмены; это не финансовый отчёт по выкупам.

Поставки сохраняются при обычной загрузке вместе с продажами и остатками. Сумма товара в пути доступна через «Подробнее»; известный ноль не требует ручного подтверждения. Документы и состав доступны на странице маркетплейсов.

WB: запланированные поставки не уменьшают сборку. Для переданных и принимаемых поставок ожидаемый остаток — заявлено минус уже поступило в продажу; это оценка до завершения приёмки. Для принятых — принято минус поступило в продажу. Открытые документы загружаются без ограничения давности, завершённые — обновлённые за последние 30 дней. Переданная поставка старше 30 дней, некорректная дата или неизвестные счётчики требуют проверки только по затронутым товарам.

Ozon: числовой источник — transit_stock_count из аналитики остатков по всем складам. Документы заявок показывают состав и статус; их количество повторно не прибавляется. Заявленное requested_stock_count не считается отправленным товаром. Отсутствующая строка аналитики не означает ноль.

Подтвердите товар в пути вручную в дополнительных настройках строки, только если API не сообщает его целиком или требуется корректировка. Укажите общее число единиц WMS по включённым площадкам; отсутствие поставок подтвердите явным нулём. Это уже отправленный товар: короба, пока зарезервированные черновиком отгрузки WMS, сюда не включайте. Ручное значение заменяет API и требует нового подтверждения после успешной загрузки или изменения подключений.

Строка тематики показывает целевой запас, остаток площадок, свой готовый запас, оставшийся объём сборки и дополнительное число коробов. Короба общего накопителя уже считаются готовыми для расчёта сборки; для отгрузки их ещё надо разместить. Кнопка создания недоступна при неизвестных, старых или неполных данных, нехватке свободного сырья либо отсутствии дополнительной потребности.

«Создать задание» добавляет обычное задание в свободную очередь. После создания расчёт изменится с учётом этого задания. Сотрудник выполняет привычную сборку через QR зон. Предложения не резервируют товар до нажатия. Сборка не создаёт отгрузку автоматически.

Первая версия не учитывает сезонность, акции, историю отсутствия товара, производственную мощность и будущую вместимость готового хранения. Реальное подключение подтверждается только успешной загрузкой с вашим ключом и сверкой нескольких товаров с кабинетом.

## Резервное копирование

Помимо PostgreSQL сохраняйте .data/marketplace-secret.key отдельно с правами 0600 либо безопасно сохраняйте заданный WMS_MARKETPLACE_KEY. Не включайте ключ в Git, общий архив с дампом или клиентские переменные NEXT_PUBLIC. При восстановлении на другом компьютере потребуется тот же ключ; без него нужно заново ввести ключи кабинетов. Пока подключений нет, файл не создаётся.

# Подключение и план сборки

Откройте «Маркетплейсы» под руководителем. Добавьте Wildberries и/или Ozon. Для WB нужен персональный токен только для чтения с категориями Контент, Статистика, Аналитика. Для Ozon — Client ID и отдельный ключ с чтением каталога, FBO-отправлений и аналитики остатков. Не отправляйте ключи в чат; введите их в форму WMS. Сохранённый ключ ещё не означает успешное подключение.

Нажмите «Загрузить данные» для каждой площадки. Из-за лимитов WB загрузка может занять несколько минут. Проверяйте статус и дату последней успешной загрузки. При ошибке предыдущие данные сохраняются, но задания по ним блокируются до исправления. Обновление пока ручное.

Если тематики ещё нет, нажмите «Добавить тематику» в каталоге: укажите название, штрихкод и количество единиц в транспортном коробе. Код создаётся автоматически. Это запись справочника без приёмки и начисления остатков; одинаковый штрихкод с совпадающими параметрами использует существующую тематику, конфликтующие данные отклоняются. Сценарий доступен только руководителю.

В каталоге выберите тематику и количество единиц WMS в одной продаваемой упаковке. Одна книга или один набор маркеров считается одной единицей: 25 картин внутри книги и 168 цветов внутри набора не являются множителями количества. Если продаётся одна раскраска, укажите 1; для набора из 10 — 10. Нажмите «Сохранить»: предложение по штрихкоду само по себе связь не создаёт. Для расчёта необходимо сопоставить загруженные карточки включённых площадок.

В «Плане сборки» задайте период истории, горизонт запаса, страховые дни и срок доставки. Если история длиннее предыдущей загрузки, повторно загрузите данные. Расчёт использует полные дни по Москве. Он показывает оперативный спрос по заказам минус отмены; это не финансовый отчёт по выкупам.

Подтвердите товар в пути на маркетплейсы, если API не сообщает его целиком. Укажите общее число раскрасок по включённым площадкам; отсутствие поставок подтвердите явным нулём. Это уже отправленный товар: короба, пока зарезервированные черновиком отгрузки WMS, сюда не включайте. Ручное значение заменяет API и требует нового подтверждения после успешной загрузки или изменения подключений.

Строка тематики показывает целевой запас, остаток площадок, свой готовый запас, оставшийся объём сборки и дополнительное число коробов. Короба общего накопителя уже считаются готовыми для расчёта сборки; для отгрузки их ещё надо разместить. Кнопка создания недоступна при неизвестных, старых или неполных данных, нехватке свободного сырья либо отсутствии дополнительной потребности.

«Создать задание» добавляет обычное задание в свободную очередь. После создания расчёт изменится с учётом этого задания. Сотрудник выполняет привычную сборку через QR зон. Предложения не резервируют товар до нажатия. Сборка не создаёт отгрузку автоматически.

Первая версия не учитывает сезонность, акции, историю отсутствия товара, производственную мощность и будущую вместимость готового хранения. Реальное подключение подтверждается только успешной загрузкой с вашим ключом и сверкой нескольких товаров с кабинетом.

## Резервное копирование

Помимо PostgreSQL сохраняйте .data/marketplace-secret.key отдельно с правами 0600 либо безопасно сохраняйте заданный WMS_MARKETPLACE_KEY. Не включайте ключ в Git, общий архив с дампом или клиентские переменные NEXT_PUBLIC. При восстановлении на другом компьютере потребуется тот же ключ; без него нужно заново ввести ключи кабинетов. Пока подключений нет, файл не создаётся.

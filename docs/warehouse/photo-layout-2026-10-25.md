# Предварительная расстановка по фотографиям

Основа — план помещений и пять фотографий пользователя. Малый склад используется для сборки у столов, это подтверждено пользователем. Европаллета 1200 × 800 мм, полная высота 70 с небольшим см с деревянным поддоном; расстояние между ярусами 80 см. Для настройки используется оценка 750 мм и ограничение ячейки 800 мм. В приёмке высота 75 см — редактируемое начальное значение, поле явно включает поддон.

## Что перенесено

- Маленький склад: существующие A-01/A-02/A-03 сохранены как отдельные паллетные колонки. Предварительно девять колонок: шесть вдоль правой стены и три поперёк. В каждой пол и три уровня выше, всего 36 адресов.
- Большой склад: предварительно 15 колонок B-01…B-15 вдоль левой стены, по четыре адреса; справа 12 напольных F-01…F-12. Между ними центральный проход.
- Сборка: PACK-01 — прежний общий накопитель всех тематик у столов; PICK-01 — место паллеты отбора. Столы не объявляются адресами хранения.
- Коридор: IN-01 предварительно у стены, T-01/T-02 — два временных места; центральная связь помещений свободна. Назначение приёмки в коридоре — допущение расстановки, его можно изменить.
- Проёмы малого и большого помещения сохраняют свои IDs и ширины. Устранён зазор 3 см между границами коридора и большого помещения; длина большого 18,49 м по плану.

## Точность

Позиции и количество пролётов/паллетомест оценены по перспективным фото, не являются обмером. Неизвестны точные размеры балок, нагрузка, габариты коробов и полезная высота относительно балок. Перед реальной адресной маркировкой проверить сетку и фактический свободный просвет. Масса остаётся неизвестной, число 18 коробов сохраняется только как счётный потолок — высотный расчёт ограничивает размещение отдельно.

Товары по фотографиям не приходуются и не перемещаются. Существующие 11 адресов, их QR, привязки товара, партии, приёмки и задания сохраняются. Только у четырёх активных тестовых raw-паллет исправляется прежняя демонстрационная высота 1400 мм на оценочные 750 мм; количество и исторические строки приёмок неизменны.

## Применение

Одноразовый импорт требует явного локального запуска для порученной пользователем настройки, проверяет исходный снимок и requestId; под общей SQL-блокировкой применяет всю схему одной транзакцией через штатные проверки геометрии, физики, целостности, stock positions, cell versions и commit state. Публичного HTTP endpoint для импорта нет, авторизация приложения не меняется. Событие обозначает настройку схемы без выдуманного сотрудника. Прежние ledger/work_events/commands не переписываются. Перед основным импортом — проверка на отдельной копии и backup.

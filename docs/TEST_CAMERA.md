# Повторный учебный проход с телефона

Доступ: https://192.168.1.72:3443/work, в той же Wi-Fi-сети. Камера открывается кнопкой «Сканировать камерой». Одно открытие принимает один QR/штрихкод; повторное открытие того же SKU означает следующую раскраску. Рабочая зона выбирается её QR, адрес хранения не заменяет рабочую зону.

## Текущая адресация

- A-01, A-02, A-03 — стеллажи в маленьком складе.
- A-01-01 — стеллаж A-01, ярус 1; последние две цифры — номер яруса. A латинская.
- IN-01 — площадка приёмки; PACK-01 — общая паллета готовых коробов.
- WZ-IN-01 «Приёмка», WZ-PACK-01 «Сборка коробов», WZ-PUT-01 «Размещение готовых коробов» — логические рабочие зоны.

25.10.2026 существующие3секции,11адресов и3зоны переименованы штатными командами по запросу владельца. Геометрия, IDs, QR и содержимое прежних документов сохранены. SKU остаются с явной пометкой ТЕСТ, чтобы отличать учебные запасы.

## Порядок

1. Страница1: QR приёмки → QR показанной паллеты → показанный свободный адрес. Повторить для второй паллеты.
2. Страница2: QR сборки → исходная паллета «Котики» → новая этикетка короба1 →20сканов товара. Затем этикетка2 и20сканов. Если приложение снова запрашивает источник — подтвердить ту же паллету.
3. Страница3: следующее задание «Космос» открывается автоматически. Исходная паллета → этикетка3 →20сканов товара; затем этикетка4 и20сканов.
4. Страница4: QR размещения → QR любого нового собранного короба → показанный адрес. Повторить для оставшихся. Исходный адрес и повторный скан короба не нужны.

PDF содержит все11физических адресов,3рабочие зоны, новые входящие паллеты, фактические FIFO-источники заданий, товар и свободные этикетки. Названия берутся из текущей БД; номера этикеток соответствуют ещё свободному registry. После реального теста они перестанут быть свободными и понадобятся другие номера для нового круга.

# Простое рабочее место сотрудника

Пользователь одобрил отдельный телефонный процесс: начало смены → взять задание → один текущий шаг. Скан завершается Enter, принимается сервером и переводит к следующему шагу без отдельного клика. Размещение готовых коробов остаётся добровольным. Управленческие экраны сохраняются.

Работа изолирована в /private/tmp/artmate-wms-staging-employee-workspace; PostgreSQL main не используется для тестовых данных. Нужны browser QA, обязательные проверки, безопасный выпуск и локальный коммит.

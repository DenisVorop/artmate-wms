# Направление первой версии

Next.js + NestJS, Swagger/OpenAPI → Orval. FSD по образцу Artmate. По уточнению пользователя runtime использует отдельный локальный PostgreSQL (Postgres.app, порт5440); PGlite оставлен для изолированных тестов. Полноценная авторизация относится к следующему укреплению после интерактивного среза.

Crypto × Liquid Glass: графитовые поверхности, тёмно-зелёная глубина, мятный акцент, тонкие границы и аккуратная типографика. Рабочие данные и реальные операции, демонстрационные исходные товары явно обозначены.

Каркас → карта/приёмка → сборка/FIFO → частичная отгрузка → проверка в браузере. Ограничения первой версии фиксируются в README.

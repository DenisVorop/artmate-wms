# Первая интерактивная версия WMS

Цель: локально запускаемый монорепозиторий, в котором можно создать место, принять паллету, собрать короб и отгрузить часть запаса.

Пользователь разрешил автономную реализацию с агентами. Промежуточные решения принимает основной агент и фиксирует их. Коммиты не выполняются.

Архитектура и решения: ../../decisions/. Прогресс и продолжение: progress.md. Визуальное направление: design.md.

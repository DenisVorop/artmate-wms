# Понятное действие и единый список заданий

Основание: после проверки телефоном владелец сообщил, что крупный исходный адрес отвлекает от короба и действия; следующий шаг понятен лишь из подписи поля. Размещение требует четырёх сканов короб/исходный адрес/короб/назначение. Общей очереди нет. Владелец подтвердил: единый экран нужен обоим ролям.

Результат: при размещении из общего накопителя нет предварительного назначения: сотрудник сканирует любой доступный короб; при размещении крупно действие и назначение, короб уже известен системе. Уточнение владельца добавлено в ходе работы: не заставлять искать первый короб из очереди. Новые команды допускают два скана: короб подтверждает take, назначение подтверждает place. Источник и переносимый короб проверяются сервером; вымышленных сканов нет. Старая API-пара сканов сохраняется для совместимости.

Общая очередь руководителя и сотрудника объединяет реальные операции и статусы; сохраняются права, текущее задание, очередь сканов и dirty-ввод. Просмотр не берёт работу автоматически и не меняет склад.

Проверки: API команды/повтор/права/ledger/workforce, нормализация очереди, check-types/FSD/test/build, телефон320/390px, обновление в пути и показ всех заданий без потери рабочего состояния. Основная база и результат пользовательских тестов сохраняются.

## API и состояние

- `WorkspaceDto.receipts:ReceiptDto[]` required. Новый JSONB table receipts, schema5 additive, старые паллеты/партии/адреса/количества/история/commands/revision не изменяются. Legacy stored остаётся балансом, приёмки из неизвестной истории не выдумывать. Чистая база не получает seed заново.
- `PalletDto.status` добавляет `awaiting_placement`. Эти паллеты raw, locationId=null, returnLocationId=null, положительноеquantity, lot.receivedAt издокумента. До placement не занимают адреса/резервы, не доступны FIFO/сборке/перемещению/отгрузке и не входят в баланс.
- `ReceiptDto`: id,code,receivedAt,createdAt,status:`awaiting_placement|partially_placed|completed`,completedAt:string|null,pallets:ReceiptPalletDto[].
- `ReceiptPalletDto`: palletId,skuId,quantity (исходное количество документа, не остаток!),locationId:string|null,placedAt:string|null,placedByEmployeeId:string|null. После размещения locationId исторический, не меняется при дальнейших перемещениях паллеты. Физические габариты/code/lotId находятся на связанной паллете.

# Решение

Проверенные на полном горизонте модели имеют приоритет. Если преимущество не подтверждено, сезонная форма используется только как явно предварительный сценарий планирования: собственные прошлогодние даты, затем минимум три независимых раскраски того же магазина и метрики. Текущий уровень учитывается один раз.

Проверка допуска годовых моделей использует известность полного годового календаря вместо произвольных 400 наблюдений. Контрольные даты идут с шагом 28 дней; пересекающиеся окна не называются независимыми. Все пороги качества сохраняются.

Если доказана лишь месячная модель и нет годовой формы, после её конца применяется плавный переход уровня к дальнему базовому прогнозу. Это правило композиции, не доказательство качества ML на дальнем горизонте.

Финансовая форма может попасть в заказы только после стабильной проверки преобразования на парных наблюдениях 7/14/28 дней. Такой сценарий остаётся предварительным.

# Масштаб и небольшие стеллажи

Пользователь просит крупнее масштаб: секции приходится делать огромными, а при уменьшении настоящих размеров подписи становятся нечитаемыми.

Решение: метры геометрии сохраняются, рабочий вид по умолчанию около72 экранныхpx/м; отдельная кнопка fit показывает весь план. Доступное увеличение до32×fit. Масштаб изменяет только UI. Пол/стеллажи/запасы и ID не мигрируют. Навигация — кнопки масштаба, «Рабочий масштаб», «Вписать», режим руки (панорамирование) с прокруткой. Подписи экранного размера около12px, отдельный вынос выбранного малого объекта вместо обрезания всей надписи. Обводки не масштабируются. Реальная геометрия и пропорции сохраняются.

Новые section/floor default1,3×0,9 м (existing useful1300×900mm), минимальная ширина/глубина0,1 м. Minчисла применить только к плановым storage rect, не количествам или размерам поля/прохода/комнат. Физические лимиты паллет вmm остаются независимыми. Existing объекты не переизмерять. Drag storage objectsstep0,1м; drawing rooms/corridorsstep0,5 м какпрежде.

Nest DTO/Swagger→Orval,FSD,RHF/Zod сохраняются. Actualработает в `/Users/denis.voropayev/Desktop/superduper/artmate-wms`, изменениятолько `/private/tmp/artmate-wms-map-scale` досинхронизации. Backend ownsAPI/ADR016, formsagent forms/ADR017, mapagent canvas/model/CSS/ADR018, root integration/checks/browser/deploy. Пользователь ранее разрешил автономность и агентов. Без коммитов.

## Проверка

1,3×0,9 и1,2×0,8 создаются; exactfraction и поворот сохраняются; значения<0,1/NaN/null отклонены; ярусы синхронны. Рабочий масштаб даёт реальный1м≈72px независимо от исходного fit/portrait. Подписи невысокой секции в рабочем масштабе >=11px. Fit/zoom/рука не изменяютAPIrevision. После перезапуска сохраненыdata IDs/geometry. Браузерные тестовые объекты только в отдельной базе, actual данные сохраняются.

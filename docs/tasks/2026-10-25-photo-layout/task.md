# Расстановка по фото

Самостоятельно перенести существующую расстановку по фотографиям и плану, сохранив QR и учёт. Пользователь подтвердил сборку в малом складе и высоту европаллеты чуть более70см с поддоном при ярусах80см.

Файлы: docs/warehouse/photo-layout-2026-10-25.md — допущения и модель; receiving/lib/receipt-form.ts и UI — начальная высота и подпись.

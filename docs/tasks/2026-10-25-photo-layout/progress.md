# Состояние

Этап завершён. Расстановка перенесена в основную WMS одной атомарной офлайн-настройкой; приложение и прежний HTTPS-доступ телефона запущены.

Предварительная карта: 24 отдельные паллетные колонки по 4 уровня, 12 напольных позиций большого склада, PACK-01/PICK-01, IN-01 и два временных места коридора; всего 113 адресов. Положение оборудования и количество позиций оценочные; допущения записаны в docs/warehouse/photo-layout-2026-10-25.md. Существующие 11 адресов и их QR/IDs сохранены. Все ячейки стеллажей имеют высоту 800 мм.

Четыре действующие тестовые raw-паллеты получили только уточнение высоты 1400 → 750 мм. Количества, партии, приёмки, коробные составы, привязки адресов, авторизация, прежние commands/ledger/work_events и инвентаризации сохранены. Новая запись деятельности честно обозначает настройку схемы без выдуманного сотрудника. Отдельного HTTP endpoint не добавлялось.

Перед переносом: backup .data/backups/before-photo-layout-20261025.dump (0600), полная репетиция на отдельной копии и снимок всех таблиц. Импорт проверяет snapshot/requestId, занятость работой, всю геометрию, текущие паллеты, неизменность stock positions и balance; штатный commit state обновляет cell versions и revision. Строгий аудит всех таблиц после перезапуска прошёл.

Проверки: API 165 pass / 2 optional skip / 0 fail; web 356 pass; check-types, lint FSD353, production build. Типы/lint/build повторены в основном checkout. Шесть маршрутов по проходам через комнаты/двери подтверждены, включая дальнюю B-15 и F-12. Chrome1600 подтвердил 24×4, выбор яруса и новую высоту приёмки75см; финальный основной build и HTTPS390 с полем «Высота с поддоном» прошли без overflow/errors. Browser API только read-only к тестовой копии.

Собственные тестовая БД/превью и временные сессии/снимки очищены; backup и работающая основная WMS сохранены. Изменения оформлены локальным Conventional Commit; push не выполнялся.

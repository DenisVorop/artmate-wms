# Решение

Один адрес = одна паллетная позиция на одном уровне. Колонки A малого и B большого склада, напольные F большого и временные T коридора. Существующие IDs сохраняются; фото не создают учётных остатков. Импорт конфигурации атомарный с полной сверкой данных. Подробные допущения — в документе расстановки. Пользователь разрешил автономную работу и локальные коммиты.

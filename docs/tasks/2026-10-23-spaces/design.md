# Контракт пространств

## Модель/API (каноническая)

- `WarehousePlanDto` дополняется `layoutMode: 'rectangle'|'spaces'`, `spaces: WarehouseSpaceDto[]`.
- `WarehouseSpaceDto`: `id,name,archived,archivedAt,kind:'room'|'corridor',x,y,width,depth`. Ориентации нет. Координаты глобальные, минимальный размер0,5 м, максимум1000, до100 участков. Числа конечные. Участки в canvas width/depth, друг с другом не перекрываются, касаться можно.
- Старый rectangle по-прежнему даёт весь прямоугольный пол; migration4 только дополняет plan, пустые массивы не запускают seed. В spaces пол — только нарисованные участки, пустой список допустим для чистого плана. Canvas — рабочее поле, не помещение.
- `createSpace`, `updateSpace`, `deleteSpace`, `restoreSpace` — POST `/api/spaces`, `/api/spaces/:id`, `/api/spaces/:id/delete`, `/api/spaces/:id/restore`, CommandDto/idempotency/workspace response. Create возвращает server UUID. Create автоматически включает spaces mode атомарно, проверяя существующие объекты. UpdateWarehousePlan получает optional layoutMode; не принимает spaces напрямую.
- В spaces любой активный стеллаж/самостоятельный адрес/проход должен полностью входить в ОДИН участок (не через стены). Коридор допускает места временного хранения. Aisle остаётся свободным проходом, запрещающим хранение. Все прежние проверки пересечений сохраняются.
- Изменение/архивация участка проверяет все активные геометрические объекты и входы в next state; нельзя оставить их без пола. Delete — архив в существующую корзину геометрии, Restore сохраняет ID и валидирует текущие границы/пересечения. Нет hard delete. `spaces` хранит и архивные участки, пол учитывает только active.
- `EntranceDto` добавляет `spaceId:string|null` (required response); create/update optional spaceId nullable для legacy. Rectangle допускает только null. Spaces требует ID существующего участка. wall/offset относительно этого участка. Глобальный center добавляет x/y участка. Shared wall рисуется один раз и дверной проём прорезает обе совпадающие границы; дубли одного физического проёма запрещены независимо от wall/spaceId.
- При удалении участка привязанные активные входы блокируют удаление; архивные остаются историческими, восстановление требует существующего участка.
- Все команды увеличивают existing revision. Миграция сохраняет ID/геометрию/запасы/старые команды.

## UI

В конструкторе инструменты «Рисовать помещение», «Рисовать коридор», «Выбрать». Drag по фону задаёт прямоугольник с шагом0,5 м и live размерами/площадью; отпускание открывает RHF-форму имени/точных координат/размеров (ничего не сохраняется до Save). Escape/Отмена отменяет рисунок. Кнопка «Добавить по размерам» — альтернатива жесту. После save отображается настоящий пол, стены, имя и площадь. Выбор участка открывает редактирование. Нет автоматического заполнения схемой пользователя.

Нарисованные участки с именами и м² имеют разные спокойные заливки room/corridor. Вне пола — приглушённый canvas. Внутренние и внешние границы участков видны, совпадающие стены не удваиваются. У entrance в форме есть выбор помещения/коридора. Метрики показывают сумму площади без перекрытий и количество участков.

Данные основного склада не обнуляются и не подменяются preview.

## Решения взаимодействия и состояния

- `rule/gesture-has-control-alternative`: любое рисование доступно кнопкой «По размерам» и точными полями; Escape и Отмена оставляют базу без изменения.
- `rule/preserve-user-input`: ошибка пересечения, выхода за поле или занятых адресов не закрывает форму и не очищает черновик. Рисунок до Save — только UI preview.
- `rule/undo-only-when-honest`, `rule/destructive-proportional`: удалённый пустой участок находится в постоянной корзине, восстанавливается с тем же ID. Занятый участок не удаляется вместе с содержимым.
- `rule/empty-state-action`: пустой план предлагает нарисовать помещение; участок без мест предлагает добавить места. Sparse/multiroom сохраняют одну поверхность.
- `rule/cover-reachable-states`: initial loader/error, pending write, typed validation, server rejection, current polling/revision, disabled occupied deletion, archive/restore conflict предусмотрены. Прав доступа и session expiry в локальном деморежиме нет.
- Переход legacyrectangle→spaces через первый create сохраняет ID входов, если их физический отрезок точно совпал с границей первого участка. Непоместившийся активный вход отклоняет команду целиком; nearest-inference запрещена.

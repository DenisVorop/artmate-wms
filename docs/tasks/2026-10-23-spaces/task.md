# Несколько помещений на общем плане

Пользователь хочет рисовать площадь двух складов и коридора, в котором возможно временное хранение. Пример: верхнее помещение46,9 м², нижнее107,2 м², коридор30,51 м². Картинка — ориентир формы, точные размеры не выводим из обрезанного плана.

Работа автономная по ранее выданному разрешению пользователя на решения и агентов. Используем task/design/progress из discovery-loop без дополнительных checkpoint-подтверждений; пользовательское разрешение приоритетно. Без коммитов.

Код готовим в `/private/tmp/artmate-wms-spaces-builder`, основная папка `/Users/denis.voropayev/Desktop/superduper/artmate-wms` продолжает работать. Структура — Nest Swagger → Orval, FSD, RHF/Zod. Сохранность любых новых пользовательских данных обязательна. Тестовые изменения только на отдельной копии базы.

См. [контракт](design.md) и [состояние](progress.md).

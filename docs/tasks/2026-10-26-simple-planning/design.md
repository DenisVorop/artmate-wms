# Решение

Основной план: сводка потребности, список тематик с количеством коробов, коротким состоянием и понятным действием. Запаса достаточно — нейтральное состояние, не предупреждение. Нет данных — явная недоступность расчёта с действием исправления. Сырьё: показывать недостающее количество без потока дублей.

Источники API, raw warnings/blockers, коэффициенты и полная формула остаются в сервисе/документации. Подробности по запросу говорят складским языком. Неизвестные данные нельзя маскировать под ноль; права, FIFO, остатки, ключи и создание заданий сохраняются. Настройки раскрываются, текущий горизонт остаётся виден.

product-design: rule/smallest-intervention, rule/inline-before-modal, rule/cover-reachable-states, rule/error-states-recovery, rule/one-primary-action. Пользователь и AGENTS разрешили автономную разработку, делегирование и коммиты.

# Автоматическая очередь работ

Цель: задания сотрудникам появляются по подтверждённой потребности склада; заполнение общей паллеты повышает приоритет размещения и останавливает начало новых коробов.

Карта: [дизайн](design.md), [состояние](progress.md). Работа автономная по поручению пользователя; проверенные этапы фиксируются локальными коммитами.

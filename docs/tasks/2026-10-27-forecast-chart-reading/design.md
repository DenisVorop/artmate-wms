# Решение

Feature forecasting сохраняет текущий визуальный стиль и generated API. Чистые chart-period/chart функции фильтруют даты и строят геометрию; use-chart-window/use-chart-inspection хранят только интерфейсное состояние. Все источники одной тематики получают общий период. Текущий период не передаётся в backend и не меняет прогноз.

График показывает отдельные итоги факта и прогноза за видимое число известных дней, ось количества, границу будущего и значения выбранной даты. Управление — мышь, касание, стрелки/Home/End/Escape. Отсутствие факта/прогноза показано словами; ноль остаётся нулём. Выручка не выдумывается из количественного архива.

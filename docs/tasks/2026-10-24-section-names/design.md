# Подход

При открытии формы создания подобрать первый свободный номер: R-01 / «Секция 1», R-02 / «Секция 2» и так далее. Учитывать все секции и адреса, включая архивные, без учёта регистра и с обрезкой пробелов. Проверять базовый код и адреса двадцати возможных ярусов, не изменяя исходные данные.

Предложения остаются редактируемыми. Первый ярус заполняется автоматически, следующие используют прежнее добавление яруса. Явная кнопка генерации заново подставляет код, название и адреса всех новых ярусов. Открытая форма не сбрасывается от фонового обновления данных; редактирование существующей секции сохраняет её идентификаторы. Подбор на клиенте не резервирует номер: сервер остаётся окончательной проверкой уникальности при конкурентном создании. При конфликте ввод сохранён, можно повторить генерацию по обновлённым данным. API и схема базы не меняются.

Применён принцип product-design rule/smallest-intervention: готовые значения вместо обязательного ручного ввода, существующие RHF/Zod и FSD сохраняются.

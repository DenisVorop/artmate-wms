# Решение

В режиме «Конструктор» инструмент «Двигать объекты»: прямое перетаскивание помещений, коридоров, стеллажей, отдельных мест, проходов; входы привязаны к стенам. В «Обзоре» клик выбирает, без записи. «Перемещать карту» двигает только viewport. Рисование участков остаётся отдельным инструментом. Шаг координат0,1м, реальное drag требует5px pointermove, Escape/pointercancel/lostcapture отменяют, отпускание сохраняет один раз.

Space использует общий drag pipeline через id space:*; на preview одновременно смещаются границы, подписи, стены и привязанные входы. На сервер отправляются только x/y/requestId существующим updateSpace. Редактируются границы участка, содержимое с глобальными координатами не переносится группой. Сервер проверяет пересечения/покрытие существующих объектов; отказ возвращает исходное положение и понятную ошибку. Секции продолжают двигать все адреса ярусов атомарно. IDs/QR/складские остатки не меняются.

Применены product-design rules: rule/gesture-has-control-alternative — точные координаты доступны через существующую форму; rule/name-object-scope-consequence — подсказка различает границы участка и перемещение товара; rule/cover-reachable-states — click/drag/cancel/noop/pan/draw/saving/error/reload; rule/preserve-user-input — формы не сбрасываются polling.

Сохранение — серверная команда, локальный preview не считается committed. На время записи повторный drag блокируется. Для преобразования координат используется SVG CTM, масштаб/прокрутка не изменяют реальные метры. Смена режима и потеря capture отменяют незавершённый жест.

# Телефоны и запас этикеток коробов

Пользователь поручил доступ сотрудников с телефона и сценарий заранее напечатанного запаса универсальных этикеток коробов вместо принтера у каждого сборщика. Делать автономно, проверять изменения, фиксировать решения и локальные коммиты; физические действия на телефоне остаются у пользователя.

Готовность: локальный HTTPS-адрес `/work` доступен через частную сеть, localhost продолжает работать; руководитель выпускает до 1000 уникальных свободных этикеток, печатает по 100 за раз; сотрудник после паллеты сканирует свободную этикетку, сервер закрепляет её за текущим коробом, дальше обычные сканы раскрасок. Повторное использование для другого короба исключено.

Работа — в изолированной `/private/tmp/artmate-wms-phone-labels`; источник — основной checkout на c945af9. Источники переносить по исходным хешам; окружение, БД, CA/private keys и fixtures в Git не включать.

Файлы: backend — registry/DTO/controller и сборка; frontend — feature preprinted-box-labels и подсказки сборки; LAN — scripts/phone-access*, scripts/start.mjs; решения ADR055/056. Текущее состояние и продолжение в progress.md; взаимодействие в design.md.

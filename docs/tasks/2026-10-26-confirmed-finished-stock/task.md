# Подтверждённый готовый остаток для планирования

Цель: учесть сообщённый руководителем готовый товар в плане сборки, убрать снятые с продажи тематики, пересчитать потребность по актуальным данным маркетплейсов.

Карта: [design](design.md) — модель; [progress](progress.md) — состояние.

Работа небольшими проверяемыми этапами. Пользователь заранее поручил автономную реализацию, агентов и локальные коммиты; это разрешение имеет приоритет над ручными остановками discovery-loop. Физические адреса, партии и выработка не создаются из агрегатных чисел.

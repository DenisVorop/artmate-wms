# Полноценное прогнозирование с сезонностью

## Цель
Сохранить доступную историю продаж WB/Ozon с начала торговли, строить сезонные прогнозы по магазинам/товарам, проверить несколько моделей на скрытых прошлых периодах и использовать достоверный результат в плане сборки. Интерфейс руководителя остаётся простым.

## Порядок работы
Пользователь 26.10.2026 прямо поручил составить подробный план и автономно выполнять его шаг за шагом, сохраняя проверенные этапы локальными коммитами. Это разрешение заменяет ручные checkpoints/запрет автокоммитов discovery-loop. Push не разрешён. Механика сезонности для «Нового года» сохраняет небольшой запас круглый год; начальный предлагаемый минимум — 1 короб, настраиваемый.

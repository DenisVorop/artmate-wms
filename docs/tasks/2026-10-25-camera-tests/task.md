# Камера и тестовые операции

Запрос: создать тестовые приёмки и задания на сборку; дать сотруднику кнопку сканирования камерой телефона.

Критерии: камера читает QR и товарные штрихкоды через общий шлюз и очередь; одно открытие даёт один скан; ошибки разрешения и закрытие понятны; поток камеры останавливается, поздний результат не переносится в другой шаг или аккаунт. Тестовые данные явно помечены, существующие запасы и сотрудники сохраняются. Приёмка до размещения не даёт доступного остатка. Тестовые данные создаются доменными командами, после свежей резервной копии.

Архитектура: камера — общий источник строки кода, без складской логики. Декодер загружается по запросу, без внешнего CDN. Складской результат подтверждает существующий сервер.

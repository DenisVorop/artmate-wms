# Проверено

- Сервер: один Dijkstra с восстановлением ортогональных отрезков и bounded points, без изменения ранжирования. Авторитетный getWorkRoute проверяет ссылки заданий и владельцев, не выполняет команд. Согласованность схемы — по Node/WebCrypto SHA256, не общему revision.
- Интерфейс: обе метки/адреса/ярусы, стрелка, fit полного пути, ошибка/неизвестный путь/повтор GET, актуальность источника и назначения. Сканы не размонтируются, фокус возвращается.
- Обязательные check-types/lint/build прошли (FSD353). Web356/356; API161 pass +2 optional skip,0fail. В API всего163 теста, включая21 геометрию и7 защищённого рабочего маршрута. Дополнительный финальный targeted API rerun выполнен после изоляции DATABASE_URL теста.
- Chrome на собственной PostgreSQL-базе: idle map не выдумывает маршрут; any-box scan задаёт source/target; линия и обе метки помещаются на320/390px; X/Escape возвращают поле; dirty/failed scan сохраняется. Фоновый unrelated revision не сбрасывает путь. При изменении прохода новый hash принимается, задержанный старый ответ не рисуется. GET500/несовпадение hash скрывают линию, retry только читает. Истечение сессии закрывает карту. Runtime errors/overflow нет. Менялись только синтетические данные.
- Физический телефон и аппаратный сканер не управлялись; финальная проверка основного HTTPS-адреса выполняется в Chrome.

# Общая паллета сборки и второстепенное размещение

Уточнение пользователя: на сборке одна общая накопительная паллета с готовыми коробами всех тематик. Только затем сотрудник по желанию берёт второстепенное задание и размещает короба по тематическим паллетам хранения. Полный процесс в управленческой версии; мобильный экран позднее. Одна SKU на паллете остаётся правилом входящего сырья и готового хранения, исключение только накопительassembly.

Контракт design.md, статусprogress.md. Автономная реализация и агенты разрешены пользователем/AGENTS; без коммитов, main сохраняется. Работать в этом stage, actual обновить только после backup/tests/browser.

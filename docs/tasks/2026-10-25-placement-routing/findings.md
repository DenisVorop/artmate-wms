# Факты

- physical.ts: placementError и putawayPlacementError проверяют габариты, массу, высоту, тему/упаковку и входящие резервы. Эти проверки предшествуют ранжированию.
- warehouse.service.ts: getReceiptPlacementOptions выбирает по maxHeightMm/code; _putawayOptions ставит существующую физическую паллету раньше пустого адреса; _claimPutaway вызывает подбор внутри команды под общей SQL-блокировкой.
- layout.ts: footprint меняет ширину/глубину на 90/270, сохраняя верхний левый угол; globalDoorSegment переводит проём в глобальные координаты. Один физический проём общей стены не может дублироваться с другой стороны.
- dto.ts: accessSides — только количество сторон без конкретного фронта. Aisle — прямоугольник; несколько проходов могут пересекаться. Каждое оборудование находится целиком в одном помещении.
- Приёмка хранит locationId=null до размещения; origin определяется однозначным адресом привязанной зоны приёмки или единственным активным адресом receiving.

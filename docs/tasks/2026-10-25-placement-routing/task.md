# Размещение по проходам и ярусам

Цель: подбирать физически совместимое хранение с учётом пути по схеме и удобства яруса. Готовая паллета своей тематики сохраняет первый приоритет. FIFO, вместимость, транзакции, существующие назначения и ручное подтверждение не меняются.

Файлы: design.md — принятый подход; findings.md — факты модели; progress.md — текущая проверка. Автономная работа, агенты и регулярные локальные коммиты разрешены пользователем; новые подтверждения каждого шага discovery-loop не требуются в силу этого разрешения.

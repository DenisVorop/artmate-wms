# Утрата поставки и запуск новинок

Цель: исключить сгоревшую поставку Мандал, подтвердить нулевой WBостаток Собачек/Нового года и дать честный прогноз запуска. Пользователь подтвердил приоритет API перед старым отчётом кабинета и дал прямое разрешение применить изменения.

Карта: design.md — архитектура; progress.md — состояние. Работа автономная с проверками и локальными коммитами по указаниям пользователя/AGENTS, поверх обычных checkpoint discovery-loop.

# Мини-карта рабочего адреса

Запрос: при заборе товара и размещении короба открыть небольшую карту с подсвеченным местом. Подсказка должна сохранять текущую работу на телефоне.

Результат: одна кнопка «Показать на карте» возле актуального адреса, компактная read-only карта помещения и обзор склада. Подсветка физической секции/места с точным адресом и ярусом, реальные помещения/коридоры/входы/оборудование. Нет выдуманного положения сотрудника и маршрута. Карта не изменяет данные, не выполняет scan/claim и не размонтирует рабочую форму.

Сценарии: FIFO-источник сборки, назначение приёмки, исходный/целевой адрес перемещения, целевой адрес переносимого короба, источник отбора при отгрузке. Общая паллета размещения показывается только при однозначном адресе источника зоны.

Проверки: повороты90/270, ярусы одной секции, архивные адреса, локальные координаты входов, компактные320/390px, точность подсветки/яруса и сохранность pending/failed сканов. При изменении шага/адреса/личности устаревшая карта закрывается.

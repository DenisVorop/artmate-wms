# Состояние

Реализована компактная карта адреса для источника сборки, назначения приёмки, обеих сторон перемещения, размещения готового короба и отбора при отгрузке. По умолчанию показано помещение, доступен весь реальный склад; выбранная секция/место выделены, точный ярус указан отдельно.

Сохранены текущая форма, первый и ошибочный сканы. При закрытии фокус возвращается в EmployeeScan текущей операции; при смене шага/адреса/авторизации устаревшая карта закрывается. Read-only entity не импортирует редактор и не выполняет складских команд. Архитектура записана в ADR059 и AGENTS.

Проверено в staging: check-types, lint (348 source files), build; API — 127 pass, 2 optional skips; web — 346 pass, включая 8 тестов геометрии. Независимая проверка Chrome /work на 320/390px: точный адрес/ярус, обзор, X/Escape/backdrop, возврат фокуса/HID-ввод, сохранность dirty/failed source и пары приёмки, закрытие старой карты после успешного pending-подтверждения и истечения сессии, отсутствие команд при просмотре и горизонтального overflow. Дополнительно проверены карта общего накопителя PACK-01, выбор любого короба, точное назначение, восстановление переносимого короба после reload без повторного скана и сохранность ошибочного адреса при просмотре. Использовалась отдельная синтетическая база; аппаратный сканер и физический телефон не проверялись.

Установлено в основную локальную WMS. Повторные check-types, lint и build прошли. Перед остановкой создана резервная копия before-location-map-20261025.dump; после запуска сверены все 32 таблицы и metadata — данные сохранены. Финальный Chrome smoke основной сборки на localhost и HTTPS-адресе телефона прошёл: точная подсветка, возврат в поле, переключение общей очереди без потери работы; все API-запросы этого smoke были read-only к изолированной базе. Сертификат CA и адрес телефона сохранены. Проверочные сервисы, база и временные учётные данные удалены после проверки.

# История опубликованных прогнозов

Сохранять каждый успешно опубликованный расчёт навсегда, отдельно от сменяемого кэша. Показывать руководителю прогноз на момент публикации и последующий факт за те же даты, по тематике и площадке. Накапливать проверку для осторожной автоматической поправки следующих расчётов.

Продолжение: [progress.md](progress.md). Архитектура: [design.md](design.md).

Пользователь ранее поручил автономную работу, агентов и регулярные локальные коммиты. Это разрешение имеет приоритет над checkpoint-процедурой discovery-loop.

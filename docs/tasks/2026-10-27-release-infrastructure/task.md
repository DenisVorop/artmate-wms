# Подготовка WMS к релизу

Цель: воспроизводимые образы API/Web, отдельный PostgreSQL, перенос текущих данных и ключа, безопасные команды выпуска/backup/restore, CI и план первого релиза. Размещение ещё не выбрано. Готовим отдельный сервер и поддомен существующего Artmate без изменения соседнего проекта или сервера.

Рабочее дерево до начала чистое, предыдущий функциональный этап сохранён коммитом 3eac91e. Пользователь явно поручил автономную реализацию и локальные коммиты; checkpoints discovery-loop выполняются сообщениями о выбранном подходе без повторных разрешений. Push, публикация образов, DNS и реальный deploy не входят в текущую задачу.

Карта: design.md — устройство, findings.md — проверенные факты, progress.md — выполненное и оставшиеся проверки. Постоянные решения — ADR082 и docs/DEPLOYMENT.md.

# Решение

Один переход raw stored → retired внутри последнего товарного скана. Обе адресные ссылки очищаются; исходные receipt rows неизменны. Общая command-транзакция обеспечивает ledger, cell versions, replay и rollback. Подробное правило закреплено в ADR062.

Две старые исчерпанные при сборке паллеты проверяются и исправляются отдельно, без массовой миграции нулевых остатков.

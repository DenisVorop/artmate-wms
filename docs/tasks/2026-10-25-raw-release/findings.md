# Проверенные факты

В основной базе найдены две raw-паллеты stored с quantity=0: PLT-8A08FE9E на A-01-01 и PLT-21A44056 на A-03-02. Последние количественные события сырья — assembly в revision 251 и 295; соответствующие резервы исчерпаны. Перемещений нет. Единственная инвентаризация queued, счёта нет, утверждённых документов нет. Поэтому эти адреса можно освободить по уточнённому правилу без утверждения физического вывоза.

Точечное исправление предварительно выполнено на отдельной копии PostgreSQL. Строгая сверка всех строк разрешает только status/locationId/returnLocationId двух паллет, +1 версии двух ячеек, +1 workspace revision и два новых activity. Все прежние строки истории, учётные количества, cached commands и авторизация сохранены. Скрипт отклоняет изменение исходной базы после снимка и повторно проверяет факты под общей advisory lock.

Production-превью в Chrome: сотрудник 390 px сканирует последнюю раскраску при 1/2; короб закрывается, balance = 2 сохраняется, адрес сразу показывает0 паллет и «Адрес свободен для размещения». Архивная приёмка сохраняет исходный адрес; список паллет показывает «Снят с хранения». Проверка с отдельной настоящей БД, без фиктивных HTTP-ответов.

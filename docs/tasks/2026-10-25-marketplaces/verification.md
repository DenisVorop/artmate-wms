Production build, Playwright + установленный Chrome, изолированные Web3083/API4083/PostgreSQL. Все browser /api запросы перехвачены на изолированный API. ## Результаты

- Полный API suite: 177 passed, 2 optional PostgreSQL tests skipped. Новые отдельные HTTP/московские даты и последние изменения планировщика: 6 целевых tests passed. Изменённый общий FIFO helper проверен существующей полной складской цепочкой.
- Web: 369 passed. FSD: 379 файлов. check-types/build проходят. HTTPS gateway: 7 passed.
- Миграция на копии PostgreSQL: неизменны точные хеши всех 32 старых таблиц и прежней metadata, кроме schema_version; добавлены шесть пустых таблиц. Keyfile не создаётся при startup/OpenAPI.
- UI: обе площадки подключаются тестовыми ключами, каталог появляется после явной загрузки, предложение по barcode не сохраняет mapping автоматически, наборы переводятся в единицы WMS. Неизвестный transit требует явного значения, включая ноль. Задание создаётся только по кнопке и появляется в свободной очереди. Ключ не находится в local/session storage; ошибка сохраняет ввод, успех и закрытие очищают его.
- UI states: loading, 500, malformed200 и recovery; failed/partial сохраняют каталог и блокируют создание; свежая running-загрузка блокирует дубль, истёкшая lease разрешает повтор. Сотрудник не получает конфигурацию руководителя.
- Обе страницы: 320/390/1440px, без горизонтального overflow после завершения resize; mobile inputs16px, крупное имя страницы не пересекается с ролью, клавиатурный фокус проверен. pageErrors нет. Единственный console error — намеренно внедрённый503; отменённые Next prefetch не ошибки сценария.

Сохранены отдельные before/after screenshots и JSON измерений в /private/tmp/wms-marketplaces-evidence. Первый selector failure был дефектом harness; label/error semantic issue исправлен стабильным accessible name+describedby и повторён. Timing-sensitive overflow при resize перепроверен после двух кадров и свежей навигацией; неподтверждённый537px не объявлен багом. Реальный overlap роли в topbar320 исправлен scoped CSS и проверен повторно.

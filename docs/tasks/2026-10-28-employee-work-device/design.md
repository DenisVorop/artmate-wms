# Решение

Один владелец ресурсов в employee-workspace, активный только в working-смене. Shared инфраструктура не знает складских сущностей. Sentinel освобождается при смене/фоне и при позднем ответе старого запроса. AudioContext активируется в пользовательском жесте, освобождается при выходе; сигналы по результату общей обработки, без изменения очереди и команд. Подробности в ADR083.

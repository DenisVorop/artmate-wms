# Экран и звуки сотрудника

Цель: удерживать рабочий экран во время смены и различать принятый/отклонённый скан на слух.

Пользователь явно поручил реализацию; повторное согласование не требуется. Один этап: устройство → общая очередь сканов → проверки. [Решение](design.md), [состояние](progress.md).

# Решение

Причина: изменение настроек делает старую presentation несовместимой и обнуляет forecast goals до публикации. readPlanningPresentation восстанавливал новый saved plan из fallback и называл его предыдущим расчётом, хотя он ещё не был посчитан по сезонной модели.

При cacheCurrent=false bootstrap из snapshots запрещён. Совместимый прежний план продолжает показываться неизменным и неисполняемым. Без совместимого результата planStatus=unavailable, UI сохраняет настройки доступными, но не показывает временные количества и кнопки создания заданий. После штатной публикации worker появляются новые количества; настоящий ноль остаётся допустимым. Публичный DTO не меняется.

# Месячная подготовка еженедельных отправок

Пользователь уточнил: отправки каждую субботу, готовые короба нужны на месяц вперёд. Разделить ближайшую отправку и объём сборки для всех суббот следующих 30 календарных дней. Автономная реализация и локальные коммиты разрешены; используем discovery-loop для resumable фиксации решений.

Дополнительное уточнение: прогноз нужен по каждой тематике в штуках отдельно для WB/Ozon, с разбивкой ближайших 30 дней по неделям. ML оценивается на точном 30-дневном горизонте независимо от дальнего покрытия маркетплейсов. Продажи и объём отправки — разные показатели.

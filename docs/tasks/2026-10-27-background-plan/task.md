# Фоновое обновление плана

Цель: сохранённый расчёт сразу виден после открытия страницы, во время импорта и при его ошибке; новые данные заменяют его атомарно. Выполнение заданий проверяется по актуальным данным отдельно.

Карта: design.md — решение; progress.md — текущее состояние; findings.md — проверенные причины.

Пользователь разрешил автономную реализацию и локальные коммиты; эти указания определяют рабочий процесс поверх обычных checkpoint навыка discovery-loop.

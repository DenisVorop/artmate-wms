# Таблички зон и мест на А4

Пользователь попросил печатать несколько QR зон и мест на обычном А4 с крупными названиями для вырезания и приклеивания. Готовый сценарий находится в `/labels/a4`. Архитектурные решения: [ADR 053](../../decisions/053-a4-warehouse-signs.md). Текущее состояние: [progress](./progress.md).

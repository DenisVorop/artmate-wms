# Печать табличек А4

## Сейчас

Реализованы выбор активных зон/адресов, отдельный экран предпросмотра и четыре таблички на листе А4. Интеграция в карту, QR адреса/зоны и single-label страницу. Изменений API и БД нет. Проверенная реализация перенесена из `/private/tmp/artmate-wms-a4` в основной репозиторий с проверкой отсутствия конкурентных изменений. В основном репозитории check-types, FSD lint и production build пройдены повторно. Локальная WMS перезапущена на 3080/4080 с прежней базой.

## Проверка

- check-types и FSD lint пройдены.
- Полный yarn test: API 121 passed, 1 conditional skipped; web 316 passed, включая 18 новых тестов набора А4.
- Production build пройден. Первоначальный запуск из копии с внешним symlink node_modules не поддерживался Turbopack; исправлена среда проверки локальным клоном зависимостей, исходный конфиг проекта не менялся.
- Первоначальные HTTP-тесты были ограничены sandbox listen EPERM; повторный разрешённый запуск полного набора прошёл.
- Headless Chrome, production preview 3083, только тестовые API-ответы: выбор, фильтр, URL preselection, девять табличек/три А4, четыре зоны/один А4, длинные названия без пересечений, mobile390 без горизонтального overflow. Прежняя этикетка печатается 100×70. Архивирование, ошибка SVG, отказ API/retry и выход из аккаунта проверены.
- Найден и исправлен тёмный фон полей PDF через print `:root` light scheme (специфичность важна: html не перебивал :root dark). PDF отрендерен и просмотрен: поля RGB255/255/255, текст и QR не пересекаются. Предельные 160-символьные названия и 80-символьные коды прошли повторную проверку после адаптации шрифта/размера QR.
- Итоговый браузерный прогон повторён после всех исправлений. Pypdf подтвердил: 9 табличек/3 страницы 210×297, 4 зоны/1 страница 210×297, прежняя single label/1 страница 100×70, заблокированная печать/1 страница А4 с объяснением. Без лишних пустых страниц.
- Доказательства: `/private/tmp/wms-a4-evidence/result.json`, `print-metrics.json`, `desktop.png`, `mobile.png`, `nine-signs.pdf`, `four-zones.pdf`, `single-label.pdf`, `blocked-print.pdf`; предельные размеры — подпапка `stress`. Это тестовые данные, не рабочий склад. Axe не запускался (зависимость отсутствует); performance и сетевые параметры оборудования не измерялись, физическая печать не подтверждена.
